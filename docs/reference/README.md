# 参考资料（reference）

外部系统与既有实现的事实性资料，供设计/规划时引用。**只放可引用的结论，不放推导过程。**

| 目录 | 内容 | 用途 |
|---|---|---|
| [`claude-reverse/`](claude-reverse/README.md) | Claude 桌面应用 + Claude Code CLI 的逆向实测结果：布局度量、快捷键、菜单树、设计 token、图标码位、工具/命令清单 | 规划 Claude 风格 UI 或 CLI 能力面时的数值与命名依据 |

约定：

- 数字必须**可溯源**（来源、版本、哈希写在各自目录的 `SOURCES.md`）。
- 结论与推导分离：`spec/` + `data/` 可直接引用，`reports/` 用于追证。
- 不收录原始二进制、字体文件、图形素材与专有文本原文。
