## 勘察与方案

- 隐藏 `reg.exe` 的 stdout 不是稳定 UTF-8。本机中文安装路径实际被解码为替换字符，安装版降为 portable。改用固定 PowerShell Registry API + 显式 UTF-8 输出；保持 realpath + 精确 exe + 卸载器验证。
- 下载缓存构造异常会使全部 IPC 消失。主进程始终注册受信 IPC，缓存暂不可用时返回明确失败并允许重试，不把失败当作不支持。
- 页面已有单独发现状态与执行状态。沿用两者，执行能力就绪后以一个主动作展示进度、验证、准备安装和失败；手动资产入口收进展开项。
- 安装阶段原有维护闸门拒绝活跃 Agent，不强杀。补私有只读检查、明确忙原因和浏览器检查，原生确认后重新获取维护锁，避免预检与退出间竞争。
- helper 保持进程身份、排他锁、备份/回滚与实际运行版本确认。补验证遇到的真实缺陷，禁止用展示版本替代执行证据。
