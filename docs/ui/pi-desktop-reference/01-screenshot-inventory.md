## 3. 截图场景分类体系

根据实际截图内容，24 张截图划分为 **6 大功能与视觉场景**：

### 分类 A：主界面空状态与全局外壳 (Home & Shell Baseline)
- **包含截图**：`REF-001`, `REF-002`, `REF-003`, `REF-015`
- **核心关注点**：
  - 侧边栏展开（275px）与完全折叠动画过渡。
  - 连续型 46px 顶部导航条（Breadcrumbs + Action icons）。
  - 吉祥物 Logo (100px GIF/PNG) 与居中对齐空状态。
  - Onboarding 引导清单卡片布局与交互。
  - 浮动底部输入框（Composer）在 Home 模式与 Thread 模式下的几何形态。

### 分类 B：全屏设置中心 (Full-Page Settings Center)
- **包含截图**：`REF-004`, `REF-005`, `REF-006`, `REF-007`, `REF-008`, `REF-009`, `REF-010`, `REF-011`, `REF-012`
- **核心关注点**：
  - 全屏接管布局（Settings Full-Page Shell），无主界面侧边栏，改为左侧 275px 设置分类导航栏。
  - 导航分类（偏好、智能体、工作区、系统）与搜索过滤。
  - 底部固定的 `< 返回应用` 按钮（32px 高度，与主界面 footer 水平对齐）。
  - 右侧统一卡片流（Settings Group / Settings Row），彻底消除表格线条，采用 `--ds-tile` 柔和色块。
  - 控件规范：开关（SettingsToggle）、分段选择器（SegmentedControl）、下拉选择（SettingsMenuSelect / Select）、滑块、徽章。
  - 二级子页面：技能市场（REF-009）的双列卡片网格与分类标签。

### 分类 C：供应商与模型服务模态框 (Provider Setup Modals)
- **包含截图**：`REF-013`, `REF-014`
- **核心关注点**：
  - Viewport-fixed 模态弹窗系统（Portal to `#pi-desktop-overlays`）。
  - 遮罩层 `--ds-scrim`（暗色 45% 黑色，浅色 28% 弱遮罩）。
  - 4 列卡片网格布局（订阅登录 vs API Key 连接）。
  - 服务配置双栏布局：左侧模型抓取与选择，右侧凭据与已选模型优先级拖拽。

### 分类 D：会话流与流式执行 (Conversation & Streaming Runtime)
- **包含截图**：`REF-016`, `REF-017`, `REF-021`
- **核心关注点**：
  - 消息气泡层次：用户消息为右侧独立圆角胶囊气泡；AI 回复为无背景纯 Prose 直出。
  - 执行中与完成状态指示器（`✨ 执行中` / `✨ 运行完成`），折叠式思考过程（Thinking block）。
  - 速度指标胶囊（`29 tokens/s · 8.4K`）与模型标签。
  - 消息悬停动作条（Timestamp, Copy, Edit, Delete, Branch, Regenerate）。
  - 滚动锚点与向下直达悬浮按钮。

### 分类 E：右侧工作区与多任务标签 (WorkPanel & Workspace Tabs)
- **包含截图**：`REF-003`, `REF-018`, `REF-019`
