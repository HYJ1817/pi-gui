- 官方旧版安装程序及官方 SHA256；本分支经标准 `npm run build:app -- --rebuild`、`npm run build:installer` 生成的候选安装程序及 SHA256。候选不是已签名的 Release；正式签名后的验证仍须走现有发布审批。

## 执行与保留证据

1. 记录 Windows 版本、独立用户环境、旧/新安装器字节数和 SHA256。在默认每用户位置安装旧版，确认 HKCU 卸载记录、快捷方式、卸载程序及启动后的实际后端版本。
2. 在该账户的测试数据目录建立项目、会话、模型/供应商、合成 OAuth 状态、设置、草稿、Runtime 七类哨兵；记录路径、数量和哈希，不记录 payload。
3. 用多会话活动、工具调用、待审批验证拒绝更新；结束任务后明确确认更新，记录主/后台进程正常退出、助手等待结束、NSIS `/S /D=<原目录>` 退出码。不得 `taskkill /F`。
4. 确认原安装目录落地版本、重启后的 `app.getVersion()` 和真实后端版本一致，注册表与快捷方式仍正确；对比七类哨兵哈希。
5. 再次启动，确认 `pending.json` 已消费，完成提示不重复。保留助手结果、排他锁观察、截图和时间记录；不把真实凭据放进报告。
6. 在快照或另一可还原测试安装上验证安装失败回滚，确认旧版本仍能启动且数据哈希不变。无隐藏交互窗口；超时安装器退出前不回滚或启动第二个安装器。

只有这些实测证据齐全，才将本项改为通过。本文件不授权创建账户、启用系统功能、合并 main 或发布 Release。
