# Z4-1 隔离原型：协同编辑数据层

本目录是 Z4-1 设计任务的隔离原型，**不是生产模块**：不接入 `server/`、`public/`、
生产启动入口，也不在 `package.json` 的 npm test 链内。设计说明见
`docs/Z4-1-collaborative-editing-design.md`。

## 文件

| 文件 | 内容 |
|---|---|
| `collab-doc.js` | 数据层（纯数据 + 纯函数）：文档模型、闭集操作 schema、事务化批量应用、幂等日志（opId + 内容指纹，FIFO 500 条）、Agent 建议（预览/接受/拒绝）、撤销/重做。除 `node:assert` 之外的依赖为零，无 DOM、无 IO、无网络 |
| `collab-test.mjs` | 35 项数据层测试，覆盖任务验收点 12 项（编号 1–12 与设计文档 §7 对照表一致） |
| `README.md` | 本文件 |

## 独立复核方法

```bash
node prototype/z4-1-collab/collab-test.mjs
```

预期输出（2026-10-25 实测，Node v24.22.1，Windows，在本 Worktree 内运行）：

```
Z4-1 原型数据层测试：35 通过，0 失败（共 35 项）
```

退出码 0。断言总数为 35（33 项初版 + 审查收尾新增的 4c/4d 两项）；
任何一项失败会打印 `✗` 与失败信息并以退出码 1 结束。

| # | 验收点 | 测试项 |

## 验证边界（防过度宣称）

- 以上全部是**数据层**验证：不涉及任何 GUI、排版、交互或真实窗口。
- 未接入生产代码，`npm test` 不包含本目录；本原型的通过结论不构成生产集成证据。
- 测试全部使用内存构造的文档，不读写用户真实数据（符合 AGENTS.md 硬约束）。
